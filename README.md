# prgmBADAPPLE

I think it's obvious what this does.

## Usage

1. Download the zip release.
2. Send the .8xp and various .8xv files to your calculator.
3. Run prgmBADAPPLE.

If you are on OS version 5.5+, you may need to use a jailbreak. Check out
[arTIfiCE](https://yvantt.github.io/arTIfiCE/) for more details.
